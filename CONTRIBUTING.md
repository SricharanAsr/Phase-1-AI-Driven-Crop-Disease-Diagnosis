# Contributing to AI-Driven Crop Disease Diagnosis

Thank you for your interest in contributing to our project! We welcome all contributions that help improve agricultural diagnostic accuracy and accessibility.

## Code of Conduct
This project follows our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

### Reporting Bugs
If you find a bug, please open an issue with:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Your environment (Python version, OS, PyTorch version).

### Suggesting Enhancements
We welcome ideas for new features or improvements to the 3-stage pipeline. Please open an issue to discuss your ideas first.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/awesome-feature`).
3. Follow the project's coding standards (see `.editorconfig`).
4. Ensure all tests pass (`make test`).
5. Submit a pull request with a detailed description of your changes.

## Development Setup
1. Clone your fork.
2. Install dependencies: `pip install -r requirements.txt`.
3. Set up pre-commit hooks (if applicable).

## Coding Standards
- Use Google-style docstrings.
- Follow PEP 8 for Python code.
- Ensure type hinting is used for all new functions.
